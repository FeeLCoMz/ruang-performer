# Screenshots Required

Place the following screenshot files here before publishing to Play Store:

| File | Size | Usage |
|------|------|-------|
| `screenshot-mobile.png` | 540×960 px | Play Store listing (narrow / phone) |
| `screenshot-desktop.png` | 1280×800 px | Play Store listing (wide / tablet) |

Tips:
- Take real screenshots from the running app
- Minimum 2 screenshots required by Play Store
- You can add more (up to 8) for a better listing
